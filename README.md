# Admin Dashboard - The Odin Project

Welcome to the repository for my Admin Dashboard project, built as part of The Odin Project curriculum. This project focuses on mastering intermediate CSS layout techniques, particularly CSS Grid.

## 🎯 Project Objectives

The primary goal of this project was to design a complete, modern, and responsive admin dashboard layout using only HTML5 and CSS3.

- More specifically, this project allowed me to practice and deepen my understanding of:

- Deep usage of CSS Grid properties (explicit and implicit grids, grid-template-areas, grid-template-columns/rows, etc.).

- Combining CSS Grid and Flexbox to structure complex UI elements.

- Creating a fixed screen layout featuring a sidebar, a header, and a main content area.

- Integrating user interface visual elements (cards, project lists, announcements, trending sections).

## 🛠️ Technologies Used

- HTML5: Semantic page structure.

- CSS3: Styling, layout using CSS Grid and Flexbox, CSS variables.

- SVG / Icons: Vector icons to enhance the user interface.

## 📐 Layout Structure (CSS Grid Architecture)

The page architecture relies on a main CSS Grid divided as follows:

1. Sidebar: Positioned on the left, spanning the entire height of the screen.

2. Header: Located at the top right, containing the search bar and user profile information.

3. Main Content: Divided into two major subsections:

- A main section (left side) displaying recent projects as a grid of cards.

- A sidebar-like section (right side) displaying "Announcements" and "Trending" items.
